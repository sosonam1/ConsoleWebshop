# Java ConsoleWebshop

A simple webshop application written in Java. This project is designed to practice object-oriented programming (OOP) concepts such as classes, objects, encapsulation, collections, and user interaction through a console application.

## Features

* View available products
* Add products to the shopping cart
* Remove products from the shopping cart *(planned)*
* Display the shopping cart
* Calculate the total price
* Place an order
* Basic stock management

## Technologies

* Java 26
* Maven
* IntelliJ IDEA (recommended)
